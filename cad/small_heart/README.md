# Small-Heart CAD

This directory contains custom mechanical designs used with the HEartLab small-heart whole-organ configuration.

The current design set is divided into three principal assemblies:

1. **Main support** – supports and positions the rotating cannula assembly;
2. **Cannula** – provides the mechanical interface between the perfusion line and the isolated heart;
3. **Serpentine support** – maintains the heat-exchange serpentine in a vertical and mechanically stable position.
