
# Large-Heart Heart Support

This assembly supports the ex vivo heart and connects it mechanically to the main rotational support.

The system consists of a central circular support connected to the rotation shaft and six ratcheting mechanisms positioned around the support.

The ratcheting mechanisms provide adjustable attachment points for supporting the heart while allowing the support geometry to accommodate variations in organ size and shape.

## Custom components

### Circular support

**Quantity:** 1

The circular support forms the primary structural element of the heart-support assembly.

It connects to the main rotation shaft through a flange and provides mounting positions for the six ratcheting mechanisms.

Available files include:

- Fusion source/archive;
- STEP model;
- PDF drawing;
- STL file, where provided.

### Ratchet mechanism

**Quantity:** 6 complete mechanisms

Each mechanism consists of:

- ratchet;
- pawl;
- housing;
- small return spring.

The CAD assembly contains the custom components of the mechanism. The spring is an off-the-shelf component and is not included as a custom CAD model.

STL files are provided separately for:

- `Ratchet`;
- `Pawl`;
- `Housing`.

Six copies of each printed component are required for one complete heart-support assembly.

## Off-the-shelf / non-distributed components

The following components are required but are not provided as custom CAD models:

| Component | Specification | Quantity | Notes |
|---|---|---:|---|
| Connecting shaft | 5 mm diameter, ≥200 mm length | 1 | Connects the heart support to the main support |
| Flange / shaft interface | Compatible with 5 mm shaft | 1 | Connects circular support to shaft |
| Ratchet spring | Small return spring | 6 | One per ratchet mechanism |

Exact dimensions and sourcing information should be included in the bill of materials where available.
