# Large-Heart CAD

This directory contains custom mechanical components developed for the large-heart whole-organ configuration.

The current mechanical system is divided into three main assemblies:

1. **Heart support** – supports and positions the heart within the experimental setup;
2. **Main support** – supports the heart-support assembly and provides motorized rotational positioning;
3. **Transparent-PCB support** – maintains the transparent electrical PCBs in position within the tank while minimizing mechanical stress.

Commercial components required to complete these assemblies are documented but are generally not included as CAD models.
