# Epi-Endo CAD

This directory contains custom mechanical components developed for the HEartLab epi-endo mapping configuration.

The primary mechanical requirements of this setup are:

- stable positioning of the tissue preparation;
- control of cannula and perfusion-tubing movement;
- preservation of optical access to both myocardial surfaces;
- support for mirror-assisted epicardial imaging.

The mechanical system consists primarily of:

1. the main epi-endo support assembly;
2. the 45° mirror holder.

Commercial components and the cannula itself are documented where relevant but are not necessarily provided as custom CAD models.
