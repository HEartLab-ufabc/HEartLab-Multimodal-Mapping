# Mechanical Hardware

Detailed custom mechanical designs are maintained in the repository's [`cad/`](../../cad/) directory.

This hardware directory is intentionally not a second copy of the CAD library.

## CAD organization

```text
cad/
├── small-heart/
├── large-heart/
└── epi-endo/
```

The CAD library includes custom components such as:

- small-heart cannula and support system;
- small-heart serpentine support;
- large-heart heart support;
- large-heart motorized main support;
- large-heart transparent-PCB support;
- epi-endo main support;
- epi-endo mirror holder.
