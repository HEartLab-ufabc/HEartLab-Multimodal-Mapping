# Tank PCB Manufacturing Outputs

This directory contains the fabrication outputs supplied with the current KiCad project.

## Contents

- copper Gerbers;
- solder-mask Gerbers;
- solder-paste Gerbers;
- edge-cuts Gerber;
- plated-through-hole drill file;
- non-plated-through-hole drill file;
- Gerber job file;
- convenience fabrication ZIP.

The absence of a particular fabrication layer should not be interpreted as intentional without checking the source PCB.

## Before fabrication

Always inspect the manufacturing archive in a Gerber viewer and verify:

- board outline;
- copper geometry;
- electrode-mask openings;
- connector drill pattern;
- plated/non-plated holes;
- layer alignment;
- intended substrate specification;
- intended copper thickness;
- intended surface finish.

The substrate and electrode plating/finish are manufacturing specifications and are not fully defined by the Gerber files alone.
