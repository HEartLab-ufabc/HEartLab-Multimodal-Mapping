# Contact Multi-Electrode Arrays

This directory documents contact-electrical mapping arrays used by the platform.

## Small-heart whole-organ implementation

Small-heart experiments use three 16-electrode arrays:

- right atrium;
- left atrium;
- ventricle.

The small-heart arrays were implemented on thin PET-based supports to reduce mechanical loading on the cardiac surface.

Geometries used in HEartLab include:

| Array | Approximate support size | Electrode spacing |
|---|---:|---:|
| Atrial | 14 × 9.5 mm | 2 mm |
| Ventricular | 19 × 22 mm | 3 × 6 mm |

These dimensions should be checked against the fabrication drawing before being treated as manufacturing specifications.

The MEA electrical reference is connected at the aortic ring.

## Large-heart epi-endo implementation

The epi-endo configuration uses paired contact arrays positioned on opposing epicardial and endocardial surfaces.

The epi-endo arrays are preparation-specific and are documented here as the paired contact-electrical interface used on opposing tissue surfaces.

## Acquisition

The arrays interface with the electrical acquisition chain documented in the parent directory.
